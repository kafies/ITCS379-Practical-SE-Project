JULISGISTRY PROJECT REGISTRY — FORM VARIABLE MAP
============================================

1. Project name (OPTIONAL)
   Visible label:       Project name
   HTML id/name:        project_name
   JSON key:            project_name
   Python variable:     project_name
   Data type:           text/string (empty value is saved as null)
   Required:            No
   Example:             "Northern Forest Restoration"

2. Latitude (REQUIRED)
   Visible label:       Latitude
   HTML id/name:        latitude
   JSON key:            latitude
   Python variable:     latitude
   Data type:           number/float
   Allowed range:       -90 to 90
   Example:             13.7563

3. Longitude (REQUIRED)
   Visible label:       Longitude
   HTML id/name:        longitude
   JSON key:            longitude
   Python variable:     longitude
   Data type:           number/float
   Allowed range:       -180 to 180
   Example:             100.5018

4. Credit owner's name (REQUIRED)
   Visible label:       Credit owner's name
   HTML id/name:        owner_name
   JSON key:            owner_name
   Python variable:     owner_name
   Data type:           text/string
   Length limit:        160 characters
   Example:             "Example Forestry Co."

5. Amount of carbon credits (REQUIRED)
   Visible label:       Amount of carbon credits
   HTML id/name:        carbon_credits
   JSON key:            carbon_credits
   Python variable:     carbon_credits
   Data type:           number/float
   Allowed value:       Greater than 0
   Example:             2500

WHEN THE FORM IS SUBMITTED
--------------------------
The browser sends a POST request to /api/projects with a JSON object like:

{
  "project_name": "Northern Forest Restoration",
  "latitude": 13.7563,
  "longitude": 100.5018,
  "owner_name": "Example Forestry Co.",
  "carbon_credits": 2500
}
